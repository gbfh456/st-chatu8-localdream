LocalDream 接口

1. 请先在手机（或同一局域网的设备）上打开 LocalDream（本地梦境） App，载入模型并开启「API 服务器」（默认端口 8081）。
2. 插件与 App 跑在同一台手机时用 http://127.0.0.1:8081；跨设备时请填手机在局域网中的地址，例如 http://192.168.1.100:8081。
3. 如果酒馆页面是 https:// 打开，浏览器会拦截指向 http:// 本地地址的请求（混合内容）。此时请在酒馆设置里关闭「强制 HTTPS」，或改用同网段的 http 页面访问酒馆。
4. LocalDream 采用流式（SSE）返回原始 RGB 像素，插件会自动转换成图片插入聊天，并沿用当前的提示词预设、提示词替换、缓存与语气触发逻辑。
5. 手机端生成较慢，建议把超时设为 300 秒以上；长按图片「修改 tag / 重新生成」同样可用（分辨率会写入生成参数）。
